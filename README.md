# HARVION

An Adventist Ministry, Literature Evangelism, Health & Organic Outpost Platform.

## Core Features
- **Literature Evangelism Bookstore**: Physical & soft-copy books with dual pricing and preview galleries.
- **Colporteur & LE Portal**: Request to sell books, camp meeting location broadcaster, and tract sharing hub.
- **Live Ministry Broadcasts**: YouTube, TikTok Live, and Drive integration with instant global alerts.
- **Sabbath School Quarterlies**: 20 complete lessons with personal notes and PDF export.
- **Holy Bible & SOP Library**: KJV Bible reader and public domain Spirit of Prophecy classics.
- **Faith Testimonies Wall**: Cost-optimized praise and answered prayers.
- **NEWSTART Health & Edenic Living**: Plant-based recipes and organic farming guides.
- **Firebase Backend**: Cloud Firestore, Storage (`gs://vine-3e4ab.firebasestorage.app`), and Admin SDK.

## Getting Started

flutter pub get
flutter run
